HTML STRUCTURE
==============
Framework:    React/Vue SPA (Client-side rendering)
Main Section: <region> containing <ul> of <article> elements
No Tables:    Uses semantic HTML, not <table> elements
Key Elements:
  - article: Contains one tender listing
  - heading: Reference number
  - generic: Description fields, dates, location
  - links: Download and detail page links

EXTRACTION LOGIC
================
1. Navigate to pagination URL with page number
2. Wait for React/Vue to render content
3. Find all <article> elements
4. For each article:
   - Extract reference from <heading>
   - Extract description from <generic> elements
   - Extract dates matching format YYYY-MMM-DD HH:MM:SS
   - Extract tender ID from link href="/tender/{id}"
   - Extract location from labeled generic element
5. Parse dates to ISO format
6. Normalize and deduplicate
7. Insert into database


SCRAPING REQUIREMENTS
=====================
Browser Engine:  Puppeteer or Playwright
  Reason: Client-side rendering required
  Alternative: Wait for public API

Language:        TypeScript (following project pattern)
Framework:       Next.js Node.js backend
Database:        Supabase (upsert to rfqs table)

Performance:
  Pages to scrape: 68
  Time per page: 3-5 seconds (with browser)
  Total time: ~5-6 minutes
  Recommended frequency: Daily

TROUBLESHOOTING
===============
Page not rendering?
  - Check browser engine is running
  - Increase timeout (try 30s)
  - Check network connectivity

Empty results?
  - Verify URL is correct
  - Check page selector paths match current DOM
  - Ensure React/Vue has finished rendering
  - Check browser console for JS errors

Rate limited?
  - Reduce requests per second
  - Add longer delays between pages
  - Check if IP is blocked (try later)
  - Add User-Agent header

Dates won't parse?
  - Verify format (YYYY-MMM-DD HH:MM:SS)
  - Check for leading/trailing spaces
  - Handle 12-hour vs 24-hour formats
  - Validate month abbreviations
